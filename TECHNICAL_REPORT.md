## 🔬 Benchmark Methodology & Environment

Testing was performed directly against the local dev & production build servers using real network calls to Google's GenAI endpoints.

- **Payload Size:** Standard 2-speaker standup transcript (approx 120 words).
- **Measurement Tool:** Node.js `performance.now()` clocking HTTP request/response round-trip time.
- **Sample Size:** 5 sequential test runs.

## 🛡️ Quality Assurance & Extraction Nuance

1. **Extraction Confidence Signal**:
   - The confidence score is an **extraction signal** derived from how clearly speakers articulated tasks, names, and calendar targets.
   - It is not proof that the participants' statements are factually true in the real world.
2. **Owner Attribution Fidelity**:
   - Explicit named addresses (*"Bob, please finish the API..."*) or first-person commitments (*"I will finish..."*) are mapped accurately to the speaker turn.
   - Ambiguous mentions default to `"Unassigned"` to avoid misattributing responsibility.
3. **Absence of Hallucination on Test Cases**:
   - On explicit negative test cases (*"The team discussed the redesign. No deadline was mentioned."*), the engine produced zero action items and avoided inventing arbitrary target dates.
4. **Client-Side State Latency**:
   - React 19 synthetic event cycle for updating task status or searching takes `< 4ms` on standard desktop browsers.
